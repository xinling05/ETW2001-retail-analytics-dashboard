# U.S. Superstore Market Opportunity Dashboard

An interactive R Shiny dashboard developed to identify U.S. markets with stronger opportunities for profitable growth.

## Project Highlights
- integrated Superstore sales data with state-level GDP, income, and population data
- cleaned and reshaped multiple datasets
- created derived metrics such as profit margin and population-adjusted sales
- built interactive filters, KPI cards, and visualisations
- analysed profitability, discounting, and state-level market performance
